# Profile GUI (Fabric 1.21.4)

## Budowanie .jar
Opcja A (bez instalacji, z telefonu): wrzuć ten folder na GitHub -> zakładka Actions -> "Build mod" -> Artifacts -> profilegui-jar.
Opcja B (PC): zainstaluj JDK 21 + Gradle 8.12+, w folderze uruchom `gradle build`; jar: build/libs/profilegui-1.0.0.jar.
Do gry potrzebny Fabric Loader 0.16+ i Fabric API 0.119.2+1.21.4.
